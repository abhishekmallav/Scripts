# WAV to WEM

Converts WAV tracks one at a time with a `sound2wem` command script.

## Use

1. Set `SOURCE_FOLDER`, `OUTPUT_FOLDER`, and `SCRIPT_PATH` in `wav2wem.py`.
2. Run: `python wav2wem.py`.

Modify all three placeholder paths before running. The external converter must support the shown command-line options.
