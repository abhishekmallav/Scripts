# Audio to WAV

Converts MP3, M4A, and WAV files to mono 48 kHz WAV files with FFmpeg.

## Use

1. Set `$SourceFolder` and `$OutputFolder` in `audio2wav.ps1`.
2. Run it from PowerShell: `.\audio2wav.ps1`.

Modify the two placeholder paths before running. FFmpeg must be installed and available on `PATH`.
